# 리플렛 (인쇄용)

우리교회지원센터를 소개하려고 **들고 다니며 나눠 드리는 인쇄물**입니다.
내용은 모두 이 저장소의 `src/data/site.js` · `README.md` 에 있는 것만 썼습니다 — 새로 지어낸 문구는 없습니다.

## 1. 어떤 파일을 쓰면 되나

| 파일 | 언제 | 크기 |
|------|------|------|
| `dist/wcsc-리플렛-A4낱장-양면.pdf` | **사무실·가정 프린터로 바로** 뽑아 그날 나눠 드릴 때 | A4 세로 210×297mm · 양면 |
| `dist/wcsc-리플렛-3단접지-A4가로.pdf` | A4 용지에 인쇄해 **직접 3단으로 접을** 때 | A4 가로 297×210mm · 양면 |
| `dist/wcsc-리플렛-3단접지-도련3mm-인쇄소용.pdf` | **인쇄소에 맡길** 때 (재단 여백 포함) | 303×216mm · 양면 |
| `dist/wcsc-리플렛-A4낱장-도련3mm-인쇄소용.pdf` | 낱장판을 인쇄소에 맡길 때 | 216×303mm · 양면 |

프린터에서 뽑을 때는 **[실제 크기] · [배율 100%] · [양면(짧은 쪽으로 넘김 아님 — 긴 쪽으로 넘김)]** 으로 두십시오.
[용지에 맞춤] 을 켜면 크기가 줄어듭니다.

## 2. 3단 접지 — 어느 면이 표지인가

두루마리 접지(letter fold)입니다. 판 배치는 아래와 같고, **안으로 들어가는 왼쪽 패널만 3mm 좁습니다**(97mm).

```
1면 (바깥면)  ┌──────────┬───────────┬───────────┐
 왼쪽→오른쪽  │ 안쪽 플랩 │  뒷 표지   │  앞 표지   │
              │  (97mm)  │  (100mm)  │  (100mm)  │
              └──────────┴───────────┴───────────┘

2면 (안쪽면)  ┌───────────┬───────────┬──────────┐
 왼쪽→오른쪽  │ 보이는 교회 │ 사역하는 교회│ 세우는 교회 │
              │  (100mm)  │ + 커뮤니티  │ + 게시판  │
              │  (100mm)  │  (100mm)  │  (97mm)  │
              └───────────┴───────────┴──────────┘
```

접는 순서는 **안쪽면이 위로 오게 놓고 → 오른쪽 1/3 을 왼쪽으로 → 다시 한 번 왼쪽으로** 입니다.
다 접으면 [앞 표지] 가 겉으로 나옵니다.
인쇄소에 맡기실 때는 "A4 가로 3단 두루마리 접지" 라고 말씀하시면 됩니다.

## 3. 다시 뽑기

```bash
npm install                      # 처음 한 번 — 그리는 데 Chromium(Playwright)을 씁니다
npm run leaflet                  # 또는:  node leaflet/render.js
```

`leaflet-3fold.html` · `leaflet-a4.html` 을 고치고 위 명령을 실행하면 `dist/` 가 다시 만들어집니다.
글꼴은 시스템에 깔린 것을 씁니다 — 우분투 기준 `fonts-noto-cjk` (본문) 과 `fonts-nanum` (제목) 이 필요합니다.

```bash
sudo apt-get install -y fonts-noto-cjk fonts-nanum
```

## 4. 연락처는 어디서 온 값인가

리플렛에 찍힌 연락처는 **운영 DB의 `settings` 표(관리자 화면 → 센터 설정)** 에 들어 있는 값입니다.
저장소의 `src/data/site.js` 에 있는 `contact` 는 아직 `TODO(운영)` 인 임시값이라 쓰지 않았습니다.

| 항목 | 값 | 출처 |
|------|-----|------|
| 전화 | 010-4254-2270 | `settings.site.phone` |
| 이메일 | worichurchsupportcenter@gmail.com | `settings.site.email` |
| 주소 | (넣지 않았습니다 — 리플렛에서 빼기로 했습니다) | `settings.site.address` |
| 운영시간 | 평일 09:00 – 18:00 (점심 12:00 – 13:00) · 주말·공휴일 휴무 | `site.js` 기본값 — DB가 비어 있어 홈페이지도 이 값을 보여 줍니다 |
| 카카오톡 | (넣지 않았습니다) | `settings.site.kakao` 가 비어 있어, 실제 채널이 있는지 확인되지 않았습니다 |

**관리자 화면에서 연락처를 바꾸시면 리플렛도 함께 고쳐야 합니다.** 홈페이지는 DB를 읽어 자동으로 바뀌지만,
인쇄물은 그렇지 않습니다. `leaflet-3fold.html` 의 `문의` 구역과 `leaflet-a4.html` 의 `.foot` 구역 두 곳입니다.

> `src/data/site.js` 의 `contact` 도 실제 값으로 맞춰 두시길 권합니다.
> 지금은 DB를 못 읽는 상황(네트워크 오류 등)에서 홈페이지가 `02-0000-0000` 을 보여 줍니다.

## 4-1. 조판을 고칠 때

칸을 채우는 빈자리는 `<div class="grow"></div>` 하나뿐이고, **나머지 요소는 찌그러지지 않게** 막아 두었습니다
(`.panel > *:not(.grow) { flex-shrink:0 }`). 이 장치가 없으면 넘치는 내용이 조용히 눌려
잔글씨 한 줄이 통째로 사라져도 화면상으로는 멀쩡해 보입니다.

`npm run leaflet` 은 그릴 때마다 **글이 종이 끝에서 5mm 안으로 들어왔는지 검사**하고,
가까우면 어느 면의 어떤 글인지 알려 줍니다. 문구를 늘리셨다면 이 경고를 꼭 보세요.

한글 조판에서 지켜 둔 것들 —

- 눈썹줄(`.eyebrow`)의 자간은 거의 0 입니다. 로마자 줄에만 `.eyebrow--en` 을 붙여 자간을 벌립니다.
  한글에 영문 자간을 주면 "신 청 은  이 렇 게" 처럼 흩어집니다.
- 본문 줄 간격은 1.6~1.66 입니다. 한글은 라틴 문자보다 넉넉해야 읽힙니다.
- `word-break: keep-all` 로 낱말 중간에서 줄이 끊기지 않게 했고,
  `여덟&nbsp;가지` 처럼 갈라지면 안 되는 어구는 붙여 두었습니다.
- 마지막 줄에 낱말 하나만 남는 자리는 문장을 고쳐 없앴습니다. 문구를 바꾸실 때 다시 생길 수 있습니다.

## 4-2. 도련(재단 여백)은 이렇게 잡았습니다

인쇄소가 A4 보다 큰 종이에 찍고 A4 로 잘라 낼 때, 자르는 선이 조금만 어긋나도
가장자리에 흰 테두리가 생깁니다. 그래서 **배경을 재단선 밖으로 3mm 더 내보낸 판**을 따로 둡니다.

주소 뒤에 `?bleed` 를 붙이면 HTML 이 스스로 도련 배치로 바뀝니다 (`render.js` 가 이렇게 뽑습니다).

- 종이를 **303×216mm** 로 키웁니다 (297×210 + 사방 3mm).
- **바깥으로 향한 가장자리에만** 3mm 를 더합니다 — 위 · 아래 · 맨 왼쪽 · 맨 오른쪽.
  접히는 자리는 자르지 않으므로 도련이 필요 없습니다.
- 글이 재단선에서 떨어진 거리는 그대로입니다. 패널 안쪽 여백을 3mm 씩 늘려,
  종이가 커진 만큼 글도 함께 밀어 두었습니다.

> ⚠️ **`@page` 크기를 종이 크기와 맞춰야 합니다.** HTML 안의 `@page` 는 도련 없는 297×210 인데,
> 도련판은 216mm 높이라 한 면이 두 쪽으로 쪼개지고 **빈 쪽이 끼어듭니다**(2면짜리가 4쪽이 됩니다).
> `render.js` 가 그릴 때 `@page` 를 종이 크기로 덮어써 막고 있고, 뽑은 뒤 **쪽 수가 면 수와 같은지
> 확인해 다르면 경고**합니다. 이 장치를 지우지 마세요.

> 종이 크기는 인치로 넘깁니다. 밀리미터로 주면 Chromium 이 0.3mm 쯤 크게 잡습니다
> (인치로는 0.02mm 안쪽). 남는 0.2mm 는 도련 안쪽이라 잘라 내면 보이지 않습니다.

```bash
python3 -c "import segno; segno.make('https://새주소/', error='h').save('leaflet/qr-site.png', scale=14, border=2, dark='#12301F', light='#FFFFFF')"
```

## 6. 색과 글꼴

홈페이지(`assets/css/style.css`)의 팔레트를 그대로 씁니다 — 포레스트 그린 + 골드 + 뉴트럴 그레이.
`leaflet.css` 의 `:root` 에 같은 값이 들어 있으니, 홈페이지 색을 바꾸면 여기도 함께 바꿔 주세요.

## 7. 법적으로 지워서는 안 되는 문장

부동산 게시판 잔글씨는 **공인중개사법** 때문에 남겨 둔 것입니다. 두 판 모두 아래 문장이 들어 있습니다.

> 센터는 게시판을 운영합니다 — 공인중개사법상의 중개 행위는 하지 않으며, 가격·조건 협상과 계약에는 관여하지 않습니다.

자리를 줄이시더라도 이 문장은 남겨 두십시오. 저장소 README 의 같은 경고와 짝을 이룹니다.
