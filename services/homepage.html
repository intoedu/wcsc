이런 것들을 해 드립니다

반응형 디자인

휴대폰·태블릿·PC에서 모두 제대로 보이도록 설계합니다. 어르신 성도를 고려해 본문 글자 크기를 넉넉하게 잡습니다.

설교 영상 연동

유튜브 채널을 연결하면 새 설교가 자동으로 올라옵니다. 매주 따로 등록할 필요가 없습니다.

주보 · 공지 게시판

담당 집사님이 직접 올릴 수 있는 관리자 화면을 드립니다. 파일 올리기와 글쓰기 수준의 조작만 필요합니다.

교회 소개 · 오시는 길

섬기는 사람들, 예배 안내, 지도와 주차 정보를 정리해 새가족이 방문 전에 필요한 것을 모두 확인할 수 있게 합니다.

검색 노출 설정

네이버·구글 검색 등록과 기본 SEO 설정을 해 드립니다. 교회 이름으로 검색했을 때 홈페이지가 먼저 나오도록 합니다.

도메인 · 서버 대행

도메인 구입과 연결, 보안 인증서, 서버 관리까지 대행합니다. 교회에서 따로 신경 쓸 일이 없습니다.

진행 순서

홈페이지 제작은 이렇게 진행됩니다

  1. 1

    상담 · 자료 정리

    필요한 메뉴 구성과 보유 자료(사진, 소개글, 로고)를 함께 정리합니다.

  2. 2

    시안 제작

    교회 분위기에 맞는 시안을 드리고 의견을 반영합니다.

  3. 3

    개발 · 콘텐츠 입력

    확정된 시안으로 제작하고 초기 콘텐츠를 채워 넣습니다.

  4. 4

    검수 · 오픈

    테스트 주소로 확인 후 실제 도메인에 오픈합니다.

  5. 5

    사용 교육 · 운영 지원

    관리자 사용법을 교육하고 매뉴얼을 드립니다. 이후 수정 요청을 지원합니다.

제공 내역

  • 반응형 홈페이지 일체 (PC · 모바일)
  • 관리자 페이지 계정 및 사용 매뉴얼
  • 도메인 연결 및 SSL 보안 인증서 설정
  • 검색엔진 등록 (네이버 · 구글)
  • 오픈 후 지원 기간 내 수정 · 장애 대응

비용 안내

제작비 0원 + 월 관리비 3만원월 관리비

제작비는 0원입니다. 만든 뒤 월 관리비 3만원(연 36만원)만 내시면 됩니다. 이 3만원은 홈페이지를 쓰는 값이 아니라 관리비입니다 — 서버 유지와 내용 수정, 장애 대응이 여기에 들어갑니다. 교회 예산 결의를 기다리지 않고 시작할 수 있고, 만들어 놓고 방치되는 문제도 이 구조로 막습니다. 페이지 수나 게시판 종류처럼 범위가 크게 달라지는 경우에는 상담 후 항목별 내역이 적힌 견적서를 드립니다.

홈페이지 제작 관련 질문

기존 홈페이지 자료를 옮길 수 있나요?

가능합니다. 기존 사이트의 게시글과 자료를 확인한 뒤 이전 가능한 범위를 알려드립니다. 게시판 구조가 크게 다를 경우 일부는 수동 정리가 필요할 수 있습니다.

교회에 컴퓨터를 잘 다루는 사람이 없습니다.

관리자 화면은 글쓰기와 파일 올리기 수준으로 단순하게 만듭니다. 오픈 시 사용 교육을 진행하고 그림이 들어간 매뉴얼을 드리며, 이후에도 문의하시면 안내해 드립니다.

온라인 헌금 기능도 넣을 수 있나요?

계좌 안내 방식은 기본 제공되며, 결제 연동 방식은 별도 심사와 수수료가 발생합니다. 교회 상황에 맞는 방식을 상담 때 안내해 드립니다.
